# 🔖 佳文摘录

读到值得回看的文章，就在这里留一份：原文关键内容 + 出处 + 我的简评。方便以后回看，也省得重新搜。

每条都写清出处链接，不代替原文。

## 摘录模板

一篇摘录按下面四段来写，够短，也不会摘成纯搬运。

```markdown
## 《文章标题》

> 原文里最打动我的一段，保留作者原本的措辞。
>
> —— 可以引用多段，用引用块区分

**出处**：[文章标题](https://example.com/post)、作者

**为什么摘它**：两三句话说清它解决了我哪个疑问，或者推翻了我哪个判断。

**我的用法**：我自己是怎么落地这条观点的，或者不认同的地方。
```

摘录条目会陆续补充到这里。
:::
