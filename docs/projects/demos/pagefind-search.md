# 🔍 给博客装上离线全文搜索：Pagefind 小实验

不想申请第三方搜索服务的 key，也不想把读者的查询发出去。于是试了 Pagefind：构建时把索引生成进产物，运行时纯静态加载。

## 它怎么工作

`npm run build` 之后自动跑一遍 pagefind，扫描 dist 里的 HTML 生成索引和 wasm。浏览器端搜索时按需加载分片，没有后端，也没有外部请求。

## 两个真实观察

- **只索引文章**：构建日志里扫描 97 个 HTML、索引 95 页——没有 `data-pagefind-body` 的栏目首页和隐藏页被排除，搜到的就是文章。
- **中文不做词干化**：Pagefind 明确提示 zh-cn 不支持 stemming，搜索可用，但不会跨词根匹配。对中文博客这是已知取舍，不是故障。

## 实验结论

个人博客的体量下，离线搜索完全够用：零服务成本、查询隐私、索引随部署更新。代价是放弃中文词干化和排序调优。

这个实验没有独立仓库——代码就是 package.json 里的 pagefind 依赖和主题默认集成。小到算玩具，但解决了真实问题。
