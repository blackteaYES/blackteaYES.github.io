# 📦 开源项目收藏

看到值得放的仓库就记在这里。只写**别人的**项目——我自己做的那些在 [Vibe Coding 作品集](/vibe-coding/) 和 [关于我](/about) 里。

每条想清楚三件事：解决什么问题、比同类好在哪、我自己是怎么用上的。

## 记录格式示例

::: card
- title: 示例项目名
  icon: 🔍
  desc: 一句话说清它解决什么问题
  link: https://github.com/owner/repo
  tags: [分类, 语言, 场景]
:::

正文里可以接着补一段自己的使用体感，不用只留一行简介。
