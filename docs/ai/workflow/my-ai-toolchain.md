# 🧰 我的 AI 工具链：Qoder、Skill 与一只箭袋

工具换得快，值得记录的不是清单，而是分工。我现在的分工是三层。

## 工作层：Qoder

日常编码、读仓库、跑构建验证都在 Qoder Desktop 里完成。我看重的是它能读整个仓库、跑命令、把约定留在 AGENTS.md 里——Agent 是带着上下文干活，不是每次从零开始。

## 能力层：Skill

重复使用的流程收成 Skill：博客的 [精选 Skill 收藏](/ai/prompt-skill/good-skills/) 现在收了 55 条，分编码、写作、数据、研究、办公、图像、视频与动效七类。收录标准很简单：用过三次以上，才值得做成 Skill。

## 分发层：Quiver

Skill 散在各工具的目录里，对账是噩梦。于是做了 [Quiver](/vibe-coding/quiver)：内容寻址、集中对账，一处整理、多端分发。博客负责「哪些值得收」，Quiver 负责「哪台机器上是哪个版本」。

## 三层怎么串起来

遇到好 Skill → 在工作层试用 → 稳定后收进博客写清理由 → 进 Quiver 统一分发。工具退役了，Skill 还在；工具换了，只换分发层。

工具链的安全感来自：**能力沉淀在文件里，而不是任何一个工具里**。
