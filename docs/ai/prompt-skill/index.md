# 🧩 Prompt 与 Skill 工程

提示词不是「一句话魔法」，而是可以版本化、可复用、可对账的资产。这个栏目写怎么把它当工程做。

拟收录：

- Prompt 的结构化写法与分层复用
- Skill / Rules / Command 的边界与组织方式
- 提示词的回归验证：改动后怎么确认没变差
- 跨工具（编辑器、CLI、Agent）分发同一套提示词
