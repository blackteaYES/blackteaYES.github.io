## 为什么收它

把请柬需要的七组文字（日期、誓言、标题、农历宜忌、姓名、地点时间）全部枚举并要求准确，排版不翻车；新娘裁切位置、前景阴影、花束位置都指定，方形构图直接可用。

## 怎么用

替换「新人姓名 / 婚礼日期 / 婚礼地点 / 仪式时间 / 誓言短句」，保留七组文字清单与方形构图、右三分之一裁切描述。
