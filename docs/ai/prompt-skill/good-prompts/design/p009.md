## 为什么收它

01–04 四页分工（空间概念 / 建筑动线 / 家具选品 / 材料光线）是完整提案骨架；统一编辑视觉（页码块、分隔线、衬线标题）让四页像一套专业文件。

## 怎么用

替换「项目标题 / 空间类型 / 材质与配色 / 关键物件」，保留四页结构与 01–04 分工描述。避免项里那一长串（农舍风、度假短租、品牌 Logo…）按你的项目删改。

## 挑选建议
