## 原提示词

## 变体提示词 · 复古波普

有限色数丝网印刷、色块平涂套色错位，残影转译为波普重复偏移剪影。

<PromptBlock text="创作一张 9:16 竖版复古波普艺术海报，丝网印刷质感。画面内容：一位 28 岁、短黑发的东亚男性模特，身穿黑色长风衣、白色高领针织衫与宽腿西裤，静止站立在雨后夜晚的极简城市街道中央；迎面人群从他身旁穿过，化为横向移动的重影。主标题 TIME DRIFT 与副标题 Stillness inside the rush 以复古波普粗体排版准确呈现，除此之外不要任何文字、编号或日期。复古波普转换：有限色数丝网印刷，炭黑、暗红、冷灰与做旧米白纸张底色，色块平涂、边缘清晰，套色叠加带轻微错位；人群残影转译为波普式重复偏移剪影，以暗红与冷灰层层套印，表现运动与时间流逝；主体人物保持清晰锐利的色块轮廓与可辨面部，成为画面唯一视觉锚点；阴影与渐变用 Ben-Day 半调网点模拟，带复古海报纸张颗粒与做旧墨层；背景克制、留白充足。避免照片写实、复杂渐变、无限色数和精细细节。" />

## 为什么收它

长曝光残影 + 主体面部清晰的对比把概念可视化；排版极克制，只允许主副标题两行字，明确禁止 VOL 编号和日期，成品干净不模板性。

## 怎么用

替换「主标题 / 简短副标题 / 人物 / 服装」，保留「动态效果」整段（方向性运动模糊、幽灵残影）。背景克制、留白充足那句建议保留。

## 挑选建议

时尚编辑封面选这条；运动主题选 P008。复古波普变体用有限色数丝网印刷 + Ben-Day 网点，适合做印刷感海报。
