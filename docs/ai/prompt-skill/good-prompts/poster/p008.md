## 为什么收它

「字母是天空 / 球场 / 建筑的窗口」+「人物完整位于字体前方、不切过身体」把字体海报最容易翻车的构图问题显式约束住；文字白名单精简到四组。

## 怎么用

替换「主题（羽毛球→任何运动）/ 双词标题 / 辅助文案 / 年份」，保留「字母不切过脸、躯干、大腿」那条约束。关键动作元素（球拍 + 羽毛球突破字形）是点睛之笔。
