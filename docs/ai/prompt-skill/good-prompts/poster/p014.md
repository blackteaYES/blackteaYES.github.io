## 为什么收它

「年龄与章节数字始终同一个数字」+「脸、肩、手、脚伸出数字边缘」把 3D 穿出效果约束得很实；姓名、年龄、配色、短句全是槽位，模板化程度高。

## 怎么用

替换「儿童姓名 / 庆祝年龄 / 庆祝配色 / 生日短句」，保留数字一致性与穿出效果描述。成人奢华生日可去掉绘本元素、保留雕刻数字结构。
