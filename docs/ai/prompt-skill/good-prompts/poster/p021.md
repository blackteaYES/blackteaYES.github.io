## 变体提示词 · 没骨画

水下摄影转没骨画：不用墨线勾勒，以色块晕染表现水、礼服与花。

## 为什么收它

水下物理被显式约束（头发礼服气泡同向水流、折射焦散、可信浮力），标题部分藏在身体 / 礼服后方并带折射错位，是水下编辑海报里完成度最高的一条。

## 怎么用

替换「礼服 / 手持物 / 主标题 / 简短标语」，保留水下物理整段。手持物给了备选（花朵、玻璃鞋、镜子、透明面具、香水瓶），按主题挑。

## 挑选建议

水下概念海报选这条；车窗暖调选 P003。没骨画变体把水色礼服转成柔和没骨晕染。
