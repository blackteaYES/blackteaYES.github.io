## 变体提示词 · 浮雕叙事

强化浅浮雕压纹叙事：门与人物以纸面浮雕层次呈现，近看显现细节。

<PromptBlock text="创作一张 9:16 竖版浮雕叙事风格的文学艺术海报。画面内容：一道巨大、开裂的门作为主物体，一名身穿炭黑大衣的孤独微小人物立于门前；主标题 DREAM WITHIN 以超大精致衬线字体准确呈现，小号准确英文文字加入引文 All that we see or seem is but a dream within a dream、作者 Edgar Allan Poe、作品名 A Dream Within a Dream 与日期 1849。浮雕叙事转换：整体像压印在厚重乳白色纸张上，巨门与人物以同色系浅浮雕重构，通过压印高低差、边缘投影与细微明暗建立层次，裂缝以极简线刻表现；乳白暖白大面积留白，仅在门的裂缝与标题关键局部加入少量哑金色细节与柔和暖白光感；文字与压印主体共同形成中央轴线秩序，博物馆展览海报气质。构图极简、不对称且具编辑感。避免文字乱码、主体畸形、颜色杂乱、构图拥挤、廉价 3D 感和模板感。" />

## 为什么收它

「引文 → 主物体 + 微小人物 + 浅浮雕」的转译思路可复用；只用一种强调色（暗朱红）、大面积暖象牙白留白，概念与触感兼得，明确拒绝通用名言海报风。

## 怎么用

替换「原始引文 / 作者 / 作品名 / 出版日期 / 主物体」，保留「单一强调色」和「浅色压纹近看才显现」的约束。主标题用作品关键词。

## 挑选建议

文学引文海报选这条；旅行手账选 P002。浮雕叙事变体把压纹叙事感放到最大，纸面触感最强。
