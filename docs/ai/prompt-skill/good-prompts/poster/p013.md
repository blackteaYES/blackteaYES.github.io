## 为什么收它

「巨型产品 + 真人互动」结构清晰，背景大字被产品与模特部分遮挡，层次高级；文案槽位（品牌、标语、右上角署名）全部可换。

## 怎么用

替换「品牌 / 产品 / 模特 / 广告标语」，保留巨型产品与模特的互动姿势描述。单色摄影棚 + 半反射地面是干净高概念的关键。

## 挑选建议

产品创意广告选这条；时尚编辑选 P004。折纸变体把巨鞋与场景转成折纸手工感，趣味更强。
