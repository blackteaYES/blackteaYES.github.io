## 为什么收它

与 P015 同系列但互动换成剪刀手 + 逗猫，影子变成滑稽卡通伙伴呼应抬爪；日常俏皮，黄金时刻 + Portra 色调 + 50mm 浅景深。

## 怎么用

替换「人物 / 陪伴动物 / 互动方式」，保留影子涂鸦整段与黄金时刻场景。想要更活泼就加运动轨迹、爱心、星星描述。

## 挑选建议

剪刀手梗图选这条；击掌互动选 P015。稚拙插画变体线条更朴拙可爱。
