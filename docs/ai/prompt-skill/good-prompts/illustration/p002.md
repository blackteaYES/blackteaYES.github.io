## 为什么收它

目的地标题与草写副标题被要求「准确呈现」，地名文字不乱码；地标、旅行者、配色都是显式槽位，换一座城市就能复用同一套手账美学。

## 怎么用

替换「目的地标题 / 草写副标题 / 地标场景 / 旅行者」即可换城市；配色四元组（钴蓝、暖赭石、橄榄绿、陶土）保留可维持系列统一感。顶部手写排版那句别省。
