## 原提示词

<PromptBlock text="创作一张温馨的动漫风格生活肖像。人物：一位 23 岁、粉彩粉色短波波头的东亚女性。服装：超大复古红格纹法兰绒衬衫、宽松蓝色牛仔裤和黑白帆布鞋。陪伴动物：戴小格纹领巾的灰白英国短毛猫。互动方式：人物蹲下与抬爪的猫击掌。场景：黄金时刻阳光下的干净米色墙边。将人物与动物置于黄金时刻阳光下的干净米色墙边，投射出修长柔和的阴影。影子幻化成俏皮的手绘漫画涂鸦：人物影子变成可爱的 Q 版形象，动物影子变成呼应击掌动作的卡通伙伴。使用富有表现力的铅笔素描线条，将动作线、爱心、星星、蝴蝶和趣味涂鸦融入阴影。舒适的生活片段美学，现代手绘动漫与漫画插画，极简背景，柔和电影光效，真实抓拍情绪，精细毛发，自然肤色，梦幻叙事，高级编辑摄影，50mm 浅景深，Kodak Portra 400 色调，超写实。" />

动漫生活肖像转童真插画：圆润线条与童趣涂鸦，影子叙事保留。

## 为什么收它

真人与猫互动 + 影子变成手绘涂鸦，一张图两层叙事；黄金时刻 + Portra 400 色调 + 50mm 浅景深，动漫感与写实抓拍平衡得好。

## 怎么用

替换「人物 / 陪伴动物 / 互动方式」，保留「影子幻化成俏皮手绘漫画涂鸦」整段。想要更梦幻就加动作线、爱心、星星的描述。

## 挑选建议

人宠互动选这条；单人剪刀手选 P025。童真插画变体线条更圆润可爱。
