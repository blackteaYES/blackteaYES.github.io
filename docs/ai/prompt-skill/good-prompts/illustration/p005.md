## 变体提示词 · 木刻版画

铅笔底稿转黑白木刻版画，刀刻线条与块面替代素描排线。

<PromptBlock text="创作一组八格分镜脚本，黑白木刻版画风格。内容：一名短发、系围巾的少年，八格动作依次为眺望远方、跳过断崖、雨中前行并最终睡去，场景为荒野悬崖与雨中小路。保持八格分镜的网格布局与叙事顺序，每格用极简画面交代角色姿势、动作和必要背景。木刻版画转换：纯黑白表现，黑色油墨印在暖白纸张上，不加入任何颜色；线条与色块带刀刻般的手作痕迹，粗细不均、边缘发毛、转折生硬、局部断裂与缺口；雨丝、悬崖与夜空用刻刀排线与凿点表现，黑色块边缘有干刷、漏印与缺墨的粗颗粒纹理；格框线也保持手工刻痕的不规则感。整体朴拙、直接、有力量，像手工刻刀一刀一刀刻印出来的版画分镜。避免光滑矢量描边、铅笔灰调、卡通插画感和任何彩色。" />

## 可替换变量

这条没有显式槽位标签：直接改写「角色 + 四个动作 + 场景」，保留「八格 / 黑白 / 极简线条」三个硬约束即可。

## 为什么收它

把「八格 + 四个动作节拍 + 黑白极简线条」写成硬约束，出图就是可用的分镜草稿而不是单张插画；适合快速验证叙事节奏。

## 怎么用

把「短发系围巾的少年」和四个动作（眺望→跳崖→雨中前行→睡去）换成你的故事，场景同步替换；保留「八格」「黑白」「极简线条」「不要任何颜色」。

## 挑选建议

要分镜草稿选这条；要单帧完成度高的插画选 P002。木刻版画变体把铅笔稿转成黑白木刻刀味，印刷感更强。
