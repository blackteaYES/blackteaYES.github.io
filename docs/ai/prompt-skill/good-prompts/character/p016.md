## 为什么收它

编舞写成六个连续节拍（起势→律动→甩发转身→旋转踢腿→跳跃重音→低位收尾），还带叙事节拍（顾客回头看一眼、舞者害羞跟上），是结构最完整的动态提示词；避免项针对视频翻车点（面部漂移、服装变化、随机剪辑）。

## 怎么用

原提示词面向视频生成（一镜到底连续舞蹈），适合喂给支持视频的模型；只要静态帧就用变体提示词，或在原提示词后补「定格在旋转加踢腿的高潮单帧」。下方展示的是单帧效果。
