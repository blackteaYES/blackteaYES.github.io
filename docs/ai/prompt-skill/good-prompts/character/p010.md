## 为什么收它

服装层次、武器比例、统一风向、前景衣带透视都写到位；「避免插画、游戏立绘、过度 CG」那段把它牢牢按在写实电影感上。

## 怎么用

替换「人物 / 服装 / 武器 / 场景」即可换任意武侠角色；保留「低机位仰拍、全身完整入镜」和统一风向描述。想要更冷就把配色压在深青冷灰。

## 挑选建议

写实电影定妆选这条；动漫生活肖像选 P015。水墨写意变体把竹林雾气转成墨韵，最有意境。
