## 为什么收它

一次性相机美学 + 复古闪光灯 + 褪色胶片观感，Y2K 元素齐全；28mm 广角 f/2.8 + 伸出的手占前景，快照感和不完美构图刻意保留。

## 怎么用

替换「地点 / 服装 / 发型」，保留胶片（Portra 400）与 28mm 描述。想要更旧就加重「褪色、高光溢出、颗粒」。
