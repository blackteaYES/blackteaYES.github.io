# Impeccable（设计词汇）

> 返回：[🧑‍💻 编码开发 · 设计词汇](/ai/prompt-skill/good-skills/coding/#impeccable-设计词汇)

给编码 Agent 补上设计词汇和约束：可以从零搭界面，也可以优化已有页面，并尽量遵循项目自己的设计系统。

## 为什么收它

- 很多 AI 写界面只会堆组件，缺设计体系表达；Impeccable 提供一套设计词汇和判断标准。
- 既能从零构建，也能对现有页面做 audit、critique 和优化，避免每次改版都脱离规范。
- 兼容 Cursor、Claude Code、Copilot 等；Apache 2.0。
- 适合已经有设计 token、组件库和规范的项目。

## 怎么用

- 按仓库 README 安装；把项目的设计 token、组件库、规范指给它。
- 先让它 audit / critique，再按优先级改，不要一上来重写全部页面。
- 每次改动后回看设计系统约束，确认没有引入新的不一致。

## 挑选建议

- 有设计系统时最能发挥；没有的话，先让它帮你梳理一套，再谈“打磨到可上线”。
- 它不是一键美化工具，项目自己的规范仍然要作为输入。
