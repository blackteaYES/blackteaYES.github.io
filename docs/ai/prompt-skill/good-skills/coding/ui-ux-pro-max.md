# ui-ux-pro-max（UI 设计库）

> 返回：[🧑‍💻 编码开发 · UI 设计库](/ai/prompt-skill/good-skills/coding/#ui-ux-pro-max-ui-设计库)

给 AI 编程工具装一套可检索的 UI/UX 知识库：57 套 UI 风格、95 组配色、56 套字体搭配，覆盖 8 套技术栈、24 种图表类型和 29 个落地页模板。

## 为什么收它

- 接入后 AI 不再凭空猜样式，而是从风格库、配色库和字体库里按条件检索，再推荐整套方案。
- 一条 `uipro init --ai claude` 初始化，自动适配 Claude Code、Cursor、Windsurf 等工具。
- 除视觉素材外还带 UX 准则，适合快速搭出“看起来像样”的前端，而不是只堆组件。
- MIT 开源，仓库和官网都提供完整清单。

## 怎么用

- 按仓库 README 安装；在项目里执行 `uipro init --ai claude`（其他工具看 README 的对应参数）。
- 先给产品类型、目标受众和页面目标，再让它从素材库推荐方向。
- 选好方向后再进入具体页面开发；不要一次性把所有风格都塞给 AI。

## 挑选建议

- 适合快速起步和补齐设计素材；产品-specific 的信息架构、交互流程仍要自己定。
- 风格和配色很多，先定 1–2 个候选再细化，避免生成出“素材库大杂烩”。
