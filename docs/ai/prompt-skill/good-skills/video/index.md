## 挑选建议

**先看素材在哪个阶段**

- 压缩、转码、加字幕、批量处理 → ffmpeg-skill
- 中文口播删口误 → videocut
- 一堆原始素材要粗剪成片 → video-use
- 数学 / 原理讲解 → manim-skill

**再做画面与成片**

- 有产品页面和真实界面 → video-shotcraft（Remotion 工程可续改）、huashu-motion（原创动效 + 作曲 + 浏览器编辑）
- 只有主题或文章 → sweety-handdraw-video（手绘口播）、animate（分镜先确认再渲染）
- 艺术风格与口播 → huashu-art-motion
- 只想挑一种电影风格直接拍 → lemo-opuscar
- 插画、品牌视觉与可交互网页 → anidoodle
- 以角色表演为主的卡通短片 → Claude Animation Base
- 网页原生的开场、动态文字 → Bang Motion
- 研究单支 10 秒 MG 样片 → mg-styles-15

**内容分发与标识**

- 文章或视频分发成长图、卡片、公众号排版和口播视频 → article2media
- Logo 从静态到动态 → Pixel2Motion

**环境提醒**

- Node、Chrome、FFmpeg 基本是起步配置，部分还需要 Python / Playwright；装之前先看各自的环境要求。
