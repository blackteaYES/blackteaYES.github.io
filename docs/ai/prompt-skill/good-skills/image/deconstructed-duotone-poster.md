# deconstructed-duotone-poster（解构双色）

> 返回：[🎨 图像创作 · 解构双色](/ai/prompt-skill/good-skills/image/#deconstructed-duotone-poster-解构双色)

针对“AI 随便套个滤镜”的做法：先把照片拆成几个语义锚点，再用六宫格或九宫格重新演绎成双色平面海报。

## 为什么收它

- 核心是“解构”，不是滤镜：先拆语义锚点，再重组成平面印刷感版面。
- 只有两种色彩，抽象程度高；原图本来有留白空间时最合适。
- 适合建筑、山路、海岸等结构清楚的画面，也适合当灵感素材或批量艺术海报。
- 原文横评给三星：更适合做素材，不适合需要识别细节的纪实输出。

## 怎么用

- 最好提前裁成 3:4 或 4:3；选主体和空间关系清楚的原图。
- 按仓库 README 安装后上传照片，按六/九宫格模式生成。
- 需要保留更多细节时换 photo-relic 或 photo-abstract，不要硬调这个 Skill。

## 挑选建议

- 想要“双色解构”而不是“照片加滤镜”时选它。
- 它的强项是形和色块，不是叙事；做系列海报时先统一双色方案。
