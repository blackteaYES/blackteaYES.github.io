# pixel-style-poster-skill（像素海报）

> 返回：[🎨 图像创作 · 像素海报](/ai/prompt-skill/good-skills/image/#pixel-style-poster-skill-像素海报)

用细密的小点表现明暗，像老式激光打印机把图像印在带纤维纹理的米白纸上。默认输出 3:4 竖版。

## 为什么收它

- 不是普通像素化滤镜：点阵印刷感更接近孔版/激光打印，质感集中在纸纹和网点上。
- 高饱和、复杂纹理、人脸细节处理都不错；花卉、动物、近景人脸最合适。
- 也能把花束、摊位、书架、早餐这类复杂场景统一成一套点阵静物语言。
- 对原图质量很挑，适合能当海报主体的大特写；看多了容易视觉疲劳。原文横评给四星。

## 怎么用

- 按仓库 README 安装；上传 3:4 近景图，人物图优先选脸部特写。
- 生成后通常还需要再裁成 3:4；复杂场景先确认主体层次。
- 如果原图本身不够清晰，先换图，不要靠提示词硬救。

## 挑选建议

- 先用自己拍的高质量近景试效果，再决定是否用于系列海报。
- 想要“印刷点阵”而不是“马赛克像素”时选它；需要大量细节叙事时换别的风格。
