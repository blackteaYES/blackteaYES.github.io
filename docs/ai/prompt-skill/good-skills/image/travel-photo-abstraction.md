# travel-photo-abstraction（旅行抽象）

> 返回：[🎨 图像创作 · 旅行抽象](/ai/prompt-skill/good-skills/image/#travel-photo-abstraction-旅行抽象)

专为旅行照片做的抽象化 Skill：把画面里的数量、位置、节奏和间隙映射成抽象符号，而不是简单加滤镜。

## 为什么收它

- 适合元素丰富、关系清楚的旅行照：城市、街道、风景、建筑群都能被整理成一套抽象语言。
- 原图的信息层次越清楚，抽象后的信息量越大；适合做风格统一的旅行手账或作品集。
- 和 photo-abstract 的差别：它更强调“旅行中的节奏和位置关系”，不是单纯的空间减法。
- 原文横评给四星，适合系列化输出，不适合单张复杂叙事的图。

## 怎么用

- 优先选竖图；安装按仓库 README。
- 上传层次清楚的旅行照；画面太杂时先裁掉无关元素，保留主体和空间关系。
- 想做成系列时，固定同一套抽象规则和色彩，再换照片。

## 挑选建议

- 想做“旅行系列”而不是单张海报时选它。
- 单张图如果很复杂，photo-abstract 可能更干净；需要保留照片质感则选 photo-relic。
