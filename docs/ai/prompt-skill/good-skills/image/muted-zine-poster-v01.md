# muted-zine-poster-v01（低饱和纸刊）

> 返回：[🎨 图像创作 · 低饱和纸刊](/ai/prompt-skill/good-skills/image/#muted-zine-poster-v01-低饱和纸刊)

基于 gc-minimal-zine-poster 改出来的“安静版”：颜色接近单色，纸张上 70% 以上是留白，主体只占一小块。

## 为什么收它

- 把极简推到极致，适合雨天、旧书、海边、回忆这类安静情绪。
- 和 gc-minimal 同源，但更低饱和、更空；一眼能看出气质差异。
- 原文横评给三星：因为太极简，画面元素少，情感表达也比较单一。
- 适合单张情绪海报或系列留白封面；不适合需要丰富元素和强叙事的画面。

## 怎么用

- 按仓库 README 安装；给参考图或一句具体的情绪主题。
- 如果画面太空，不是加装饰，而是换更明确的主体或补一句场景。
- 默认极简构图；需要更多信息时换成 gc-minimal 或 photo-relic。

## 挑选建议

- 把它当“安静版”用，不要期待它承担复杂信息。
- 和 gc-minimal 二选一：要色彩和设计感选 gc-minimal，要极低饱和和留白选 muted。
