# photo-relic-editorial（照片版画）

> 返回：[🎨 图像创作 · 照片版画](/ai/prompt-skill/good-skills/image/#photo-relic-editorial-照片版画)

“纸上留影”：上半部分保留照片，下半部分生成一块纸感版画，从照片提取色彩和结构，用淡墨勾形。

## 为什么收它

- 比 deconstructed 更不抽象，大部分元素一眼能认出来，照片不像被“吃掉”。
- 下版画会提取原图色彩与结构，用淡墨或单色勾形，底部常有一行小配文。
- 适合建筑、天际线、水面、道路这类结构清楚的画面；原文横评给四星。
- 适合旅行记录、城市观察、建筑摄影的“照片 + 版画”双联表达。

## 怎么用

- 按仓库 README 安装；上传一张结构清楚的照片。
- 需要保留照片真实质感时优先选它；原图主体和层次越清楚，下半版画的提取越稳。
- 如果原图本身很杂，先裁出主体和主要线条，再生成。

## 挑选建议

- 想要“照片 + 版画”而不是纯抽象时选它，尤其适合建筑和旅行。
- 和 photo-revival 的区别：它保留真实照片，不把整张图重绘成插画。
