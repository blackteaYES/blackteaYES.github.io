# photo-abstract-editorial（照片抽象）

> 返回：[🎨 图像创作 · 照片抽象](/ai/prompt-skill/good-skills/image/#photo-abstract-editorial-照片抽象)

核心理念是“克制”：整张图只有照片和一块象牙白抽象面板，没有纸纹、颗粒、渐变，把空间关系抽成极简几何标记。

## 为什么收它

- 不是版画，也不是拼贴：下半部分是一块干净的象牙白面板，只留几笔几何和一行英文标题。
- 从照片里抽出几个大的空间关系，用最少的形和色重新表达；选图好时可以直接当品牌视觉。
- 适合建筑、风景、人群、旅行照；原文横评给五星，是这组里最现代、最克制的一个。
- 不适合需要叙事、细节和真实质感的画面；它故意去掉纹理和渐变。

## 怎么用

- 按仓库 README 安装；上传留白和结构清楚的照片。
- 原图的几何关系越明确，抽象面板越干净；杂乱照片先裁。
- 需要保留照片细节时换 photo-relic；需要重绘插画感时换 photo-revival。

## 挑选建议

- 想要“高级、克制、可做品牌图形”的抽象，优先它。
- 它的优势是减法；不要要求它同时保留很多元素。
