# gc-minimal-zine-poster（极简纸刊）

> 返回：[🎨 图像创作 · 极简纸刊](/ai/prompt-skill/good-skills/image/#gc-minimal-zine-poster-极简纸刊)

把一句话或一张照片做成安静的纸刊海报：仿旧纸张、大面积留白、只保留一个视觉焦点，默认 3:5 竖版。

## 为什么收它

- 不只是套模板：配了 prompt-compiler 和 quality-gate 质检流程，作者把审美当工程在打磨。
- 可以上传照片做参考，也可以只给一句话；Skill 会把短句翻成视觉隐喻再转成海报。
- 仿旧纸张 + 英文配文的气质很稳，适合情绪短句、极简人像和小景。
- 自由度很高，但也最依赖情绪表达；提示词越具体，效果越稳。原文横评给五星。

## 怎么用

- 按仓库 README 安装为 Codex / Agent Skill。
- 给参考图或一句主题；需要时补充画幅、主体和文字要求。
- 默认输出 3:5 竖版；需要其他比例时提前说明。

## 挑选建议

- 先用一句话跑几张，确认审美方向再投入；不要只写“好看一点”，会浪费它的模板能力。
- 适合安静、克制的单焦点画面；信息量大的复杂商业海报换其他 Skill。
