# scenes-gathered-zine-v1-3（撕纸拼贴）

> 返回：[🎨 图像创作 · 撕纸拼贴](/ai/prompt-skill/good-skills/image/#scenes-gathered-zine-v1-3-撕纸拼贴)

保留照片真实质感，用手撕纸的纤维边把照片和纸刊式插画连接起来；下方再加一块从照片提取的抽象色块。

## 为什么收它

- 照片不被覆盖，而是和纸刊插画拼在一起；撕纸边、纤维、色块都参与构图。
- 高饱和结构色 + 充足纸白 + 压缩成几块的大形状，美术化程度很高。
- 原文横评给六星，是作者最喜欢的一个；主体关系越清楚，结构色、抽象形状和撕纸边界越有力量。
- 一次直出就可能很惊艳，但重绘类随机性较强，需要多跑几次挑结果。

## 怎么用

- 精挑原图：优先主体清楚、关系清楚的竖图；安装按仓库 README。
- 想稳定复现时多生成几次，保留照片质感和撕纸边界。
- 如果照片本身太碎，先裁出主关系，再让它做拼贴。

## 挑选建议

- 想要“照片 + 纸刊拼贴”的编辑感，优先它。
- 原图越简单有力，效果越好；不要拿信息过载的照片硬跑。
