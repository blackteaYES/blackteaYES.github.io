## 挑选建议

**挑之前先看**

- 办公场景重复度高，优先选能固定输出格式的 Skill，比如纪要模板、任务字段齐全的拆解清单，少让模型自由发挥。

**按交付格式选**

- Word 文档 → docx
- PDF → pdf
- 演示文稿 → pptx
- 内部更新、3P、事故报告 → internal-comms
