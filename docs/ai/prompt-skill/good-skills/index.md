# ⭐ 精选 Skill 收藏

把别人分享出来、我实际用过或准备排进工作流的 Skill 收在这里。只做**索引与点评**：每条都链回原作者的分享地址，不搬运正文，也不复制 Skill 文件。

每个分类是一个独立目录，Skill 的完整内容放在各自详情页；这里只负责分类导航。

## 收录标准

三条都过才记：

1. 解决一个真实、可复现的问题；
2. 有可复用的方法，而不是只对某个项目有效；
3. 我实际用过，或者已经排进自己的工作流。

## 新增条目

新增一个 Skill：先在对应分类页加一条 `###` 条目，再在该分类目录下新建 `<skill-id>.md` 详情页。具体格式和图片规范见 [录入模板](/ai/prompt-skill/good-skills/template)。
