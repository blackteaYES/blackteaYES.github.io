## 挑选建议

**挑之前先看**

- 先看它怎么处理异常值和口径；能给出校验步骤、而不是直接吐结果的，才敢在真实数据上用。

**按任务选**

- 做表格、公式和清洗 → xlsx
- 做展示型图表 → Minicharts，数据口径仍要自己复核
